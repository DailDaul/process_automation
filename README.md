# MashUp — локальный музыкальный магазин

Полноценная учебная версия локального веб-приложения на Flask + SQLAlchemy Core + SQLite. Приложение запускается на компьютере и доступно в браузере по `http://127.0.0.1:5000`.

## Возможности
- регистрация, вход по логину/телефону/email, безопасное хеширование пароля;
- роли покупателя и сотрудника;
- каталог, поиск по ключевым словам и фильтры по формату, году, ансамблю;
- карточка издания и трек-лист;
- корзина, оформление заказа и история заказов;
- список желаемого;
- панель сотрудника: добавление товаров, изменение статуса заказов;
- отчёты о продажах и складских остатках;
- SQLite-схема с 25 таблицами, ограничениями, триггерами, индексами и представлениями.

## Запуск на Kali Linux / Linux
```bash
sudo apt update
sudo apt install -y python3 python3-venv python3-pip
cd MashUp_Full
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
cp .env.example .env
python run.py
```
Открой `http://127.0.0.1:5000`. Остановить сервер: `Ctrl+C`.

## Запуск на Windows
```powershell
py -m venv .venv
.venv\Scripts\activate
py -m pip install -r requirements.txt
copy .env.example .env
py run.py
```

## База данных
При первом запуске создаётся `instance/mashup.db`, автоматически применяется `database/schema.sql` и добавляются демонстрационные записи каталога. Не удаляй файл базы, если хочешь сохранить данные. Для сброса тестовой БД останови приложение и удали `instance/mashup.db` — при следующем запуске она создастся заново.

## Учётная запись сотрудника
В целях безопасности сотрудник НЕ создаётся с известным паролем по умолчанию. Создай обычного пользователя через регистрацию, затем один раз назначь ему роль сотрудника командой из корня проекта:

```bash
python scripts/promote_employee.py ТВОЙ_ЛОГИН
```
После этого выйди и войди заново. Обычная регистрация всегда создаёт только покупателя.

## Проверка
- Главная: `/`
- Каталог: `/catalog/`
- Проверка БД: `/health` (должен вернуть `status: ok`)
- Панель сотрудника: `/employee/`

## Важные границы учебной версии
Это локальная демонстрационная система: онлайн-эквайринг, доставка, email/SMS, восстановление пароля, CSRF-защита через отдельный пакет, загрузка обложек и частичные возвраты пока не реализованы. Заказ создаётся со статусом «Новый»; склад списывается при переводе заказа в «Завершён». При завершении заказа проверка остатка и запись складских движений выполняются в одной транзакции.

Перед публичным развёртыванием обязательно заменить `SECRET_KEY`, отключить debug, добавить CSRF-защиту и провести отдельную проверку безопасности.
